ssh远程连接加速

当前版本：
crysis@crysis:~$ ssh -V
OpenSSH_9.6p1 Ubuntu-3ubuntu13.13, OpenSSL 3.0.13 30 Jan 2024

测试1：最简连接

ssh -T bandit0@bandit.labs.overthewire.org -p 2220

测试网络：

测试延迟
Test-NetConnection bandit.labs.overthewire.org -Port 2220

追踪路由
tracert bandit.labs.overthewire.org

配置方面：

vim /etc/ssh/ssh_config

#禁用验证和DNS反向解析
GSSAPIAuthentication no
GSSAPIDelegateCredentials no
GSSAPIKeyExchange no
UseDNS no

#数据压缩和连接复用
ControlMaster auto
ControlPath ~/.ssh/control-%r@%h:%p
ControlPersist 5m
Compression yes

#安装ssh服务端使ssh.service生效
root@crysis:/home/crysis# systemctl restart ssh
Failed to restart ssh.service: Unit ssh.service not found.

dpkg -l | grep -i ssh
有输出，看到了 openssh-client 但没看到 openssh-server，说明只有客户端，没有服务端。

sudo apt update && sudo apt install openssh-server -y
sudo systemctl enable –now ssh
#--now 参数同时执行了 enable (开机自启) 和 start (立即启动)
sudo systemctl status ssh
#看到 Active: active (running) 就说明服务成功启动。
sudo sshd -T | grep -E “(usedns|gssapiauthentication|port)”
#检查输出中 usedns 和 gssapiauthentication 是否都是 no。

比较优化前后的延迟

time ssh bandit23@bandit.labs.overthewire.org -p 2220 “exit”

之前：
root@crysis:/home/crysis# time ssh bandit23@bandit.labs.overthewire.org -p 2220 “whoami”
bandit23@bandit.labs.overthewire.org‘s password:
bandit23

real 0m12.775s
user 0m0.073s
sys 0m0.001s

之后：
root@crysis:/home/crysis# time ssh bandit23@bandit.labs.overthewire.org -p 2220 “ls -l”
total 0

real 0m0.552s
user 0m0.000s
sys 0m0.005s

终端选择：

使用带有ssh优化的wsl2、git bash终端，

使用linux操作系统，

修改ssh配置，

测试延迟，

某些情况下可使用伪终端 -T连接

解决输入延迟设置：

#保活与流量控制
TCPKeepAlive yes
ServerAliveInterval 30
ServerAliveCountMax 3

IPQoS throughput
#为 SSH 连接设置“吞吐量”服务质量，可能优化大流量或高延迟下的交互。
