SUID 提权通用技巧总结

suid出现地方：（overthewire）
19 → 20：最纯粹的 SUID 提权

23 → 24：SUID 通过 cron 间接触发
通过写入 /var/spool/… 的脚本来让 cron 代你执行

26 → 27：SUID 程序，但限制更多
你可以用 strings 看出suid文件的限制权限
strings /usr/bin/bandit27-do

Usage: bandit27-do
Allowed commands: cat

危险定级：
🟥 Bandit 19 → 20
行为：提供一个 SUID 程序 bandit20-do，允许以 bandit20 身份执行几乎任意命令。

漏洞类型：

SUID 任意命令执行（典型的 Privilege Escalation 漏洞）

属于 不安全的 SUID 程序设计。

风险分级：

高危（🟥）

因为它直接允许用户以更高权限执行任意命令，几乎等于“送你提权”。

🟧 Bandit 23 → 24
行为：通过 cron 任务以 bandit24 身份执行脚本，用户可以写入脚本并间接获得 bandit24 的权限。

漏洞类型：

SUID + Cron Job 不安全配置

属于 不安全的计划任务执行漏洞（间接提权）。

风险分级：

中高危（🟧）

因为用户不能直接运行 SUID 程序，但可以通过 cron 的 SUID 行为间接提权。风险依赖于 cron 配置。

🟨 Bandit 26 → 27
行为：提供一个 SUID 程序 bandit27-do，但它只允许执行特定命令（如 cat）。

漏洞类型：

受限 SUID 程序

属于 功能受限的 SUID 提权漏洞。

虽然有限制，但依然能读取敏感文件。

风险分级：

中危（🟨）

因为它不是万能执行器，只能执行特定命令，但依然能泄露敏感数据。

SUID 提权通用技巧总结图：
┌──────────────────────────────────────────────────────────────┐
│ 🟥 1. 识别 SUID 文件 │
├──────────────────────────────────────────────────────────────┤
│ 查找系统中所有 SUID 程序： │
│ find / -perm -4000 -type f 2>/dev/null │
│ 常见高危 SUID： │
│ /usr/bin/passwd, /usr/bin/sudo, /bin/bash, /usr/bin/find │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟧 2. 分析 SUID 程序行为 │
├──────────────────────────────────────────────────────────────┤
│ 关键问题： │
│ ✅ 是否允许执行任意命令？ │
│ ✅ 是否只允许特定命令？ │
│ ✅ 是否调用外部程序？ │
│ ✅ 是否依赖 PATH？ │
│ 工具： │
│ strings │
│ ltrace │
│ strace │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟨 3. PATH 劫持（经典技巧） │
├──────────────────────────────────────────────────────────────┤
│ 如果 SUID 程序调用外部命令（如 cp、ls、cat）： │
│ export PATH=.:$PATH │
│ echo “/bin/bash” > cp │
│ chmod +x cp │
│ 运行 SUID 程序 → 获得高权限 shell │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟩 4. 环境变量劫持 │
├──────────────────────────────────────────────────────────────┤
│ 某些 SUID 程序会信任环境变量： │
│ LD_PRELOAD │
│ LD_LIBRARY_PATH │
│ PYTHONPATH │
│ PERL5LIB │
│ 如果未被清理，可注入恶意库获得高权限 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟦 5. 利用可控输入/文件 │
├──────────────────────────────────────────────────────────────┤
│ SUID 程序如果读取你可控的文件： │
│ ✅ 配置文件 │
│ ✅ 临时文件 │
│ ✅ 日志文件 │
│ 可尝试注入命令或替换文件内容 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟪 6. 利用 SUID + 解释器 │
├──────────────────────────────────────────────────────────────┤
│ 如果 SUID 程序调用： │
│ python │
│ perl │
│ ruby │
│ awk │
│ find -exec │
│ 可直接获得高权限 shell： │
│ python -c ‘import os; os.setuid(0); os.system(“/bin/bash”)’ │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ ⬛ 7. SUID 程序限制判断法 │
├──────────────────────────────────────────────────────────────┤
│ ✅ 能执行任意命令 → 无限制（如 Bandit 19→20） │
│ ✅ 只能执行特定命令 → 有限制（如 Bandit 26→27） │
│ ✅ 不能直接运行 → 间接 SUID（如 Bandit 23→24） │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ ⭐ 8. 最终目标：读取敏感文件 │
├──────────────────────────────────────────────────────────────┤
│ 常见敏感文件： │
│ /etc/shadow │
│ /etc/passwd │
│ /root/flag.txt │
│ /etc/bandit_pass/ │
└──────────────────────────────────────────────────────────────┘

SUID 提权漏洞速查表（常见可利用程序）：
┌──────────────────────────────────────────────────────────────┐
│ 🟥 最高危（几乎必定可提权） │
│ 一旦带 SUID，几乎等于“直接送你 root” │
├──────────────────────────────────────────────────────────────┤
│ 程序 | 风险机制（概念性说明） │
│—————-+———————————————-│
│ bash | 允许以程序所有者身份运行 shell │
│ sh | 同上 │
│ python | 解释器可执行系统命令 │
│ perl | 同上 │
│ ruby | 同上 │
│ lua | 同上 │
│ find | 可执行外部命令 │
│ awk | 可执行外部命令 │
│ vim / vi | 编辑器可执行外部命令 │
│ less / more | 可执行外部命令 │
│ tar | 特定参数可触发外部命令 │
│ cp / mv | 若调用外部命令可能受 PATH 影响 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟧 高危（常见于 CTF，容易利用） │
├──────────────────────────────────────────────────────────────┤
│ 程序 | 风险机制（概念性说明） │
│—————-+———————————————-│
│ env | 可调用外部程序 │
│ nice | 可调用外部程序 │
│ time | 可调用外部程序 │
│ tee | 可写入文件（可能覆盖敏感文件） │
│ nano / pico | 编辑器可执行外部命令 │
│ openssl | 某些模式可调用外部程序 │
│ nmap（旧版） | 交互模式可执行命令 │
│ git | 帮助系统可触发外部命令 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟨 中危（需要技巧或特定条件） │
├──────────────────────────────────────────────────────────────┤
│ 程序 | 风险机制（概念性说明） │
│—————-+———————————————-│
│ passwd | 若路径可控可能覆盖敏感文件 │
│ mount/umount | 可挂载伪造文件系统 │
│ chown/chmod | 若路径可控可能修改敏感文件权限 │
│ scp / rsync | 可能调用外部命令 │
│ tcpdump | 特定参数可触发脚本执行 │
│ journalctl | 可执行外部命令 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟩 低危（特定版本或配置才可利用） │
├──────────────────────────────────────────────────────────────┤
│ 程序 | 风险机制（概念性说明） │
│—————-+———————————————-│
│ man | 某些版本可执行外部命令 │
│ ftp / sftp | 某些版本可执行外部命令 │
│ gdb | 调试器可执行外部命令 │
│ lesspipe | 可能调用外部程序 │
│ cups / lp | 打印过滤器可能执行外部程序 │
└──────────────────────────────────────────────────────────────┘

SUID 程序安全审计 Checklist：
┌──────────────────────────────────────────────────────────────┐
│ 🟥 1. 基础信息收集 │
├──────────────────────────────────────────────────────────────┤
│ [ ] 是否为 SUID（-rwsr-xr-x） │
│ [ ] 所属用户（root / 特定用户） │
│ [ ] 所属组 │
│ [ ] 文件路径是否异常（如 /tmp、用户目录） │
│ [ ] 文件是否为系统默认组件 │
│ [ ] 是否为自定义编译程序 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟧 2. 程序行为分析 │
├──────────────────────────────────────────────────────────────┤
│ [ ] 是否执行外部命令（system / exec / popen） │
│ [ ] 是否使用解释器（python / perl / bash） │
│ [ ] 是否读取用户可控的文件 │
│ [ ] 是否写入用户可控的文件 │
│ [ ] 是否依赖环境变量 │
│ [ ] 是否依赖 PATH │
│ [ ] 是否使用临时文件（/tmp） │
│ [ ] 是否使用网络功能 │
│ [ ] 是否使用 setuid()/setgid() │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟨 3. 外部命令调用检查（高危） │
├──────────────────────────────────────────────────────────────┤
│ [ ] 是否使用绝对路径（如 /bin/ls） │
│ [ ] 是否使用相对路径（如 ls） │
│ [ ] 是否使用用户输入拼接命令 │
│ [ ] 是否使用 shell（system() / popen()） │
│ [ ] 是否存在命令注入风险 │
│ → 风险等级：高 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟩 4. 环境变量依赖检查 │
├──────────────────────────────────────────────────────────────┤
│ [ ] PATH │
│ [ ] LD_PRELOAD（通常被忽略，但需确认） │
│ [ ] LD_LIBRARY_PATH │
│ [ ] PYTHONPATH │
│ [ ] PERL5LIB │
│ [ ] EDITOR / PAGER │
│ [ ] TMPDIR │
│ → 风险等级：中高 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟦 5. 文件操作检查 │
├──────────────────────────────────────────────────────────────┤
│ [ ] 读取用户可控文件 │
│ [ ] 写入用户可控文件 │
│ [ ] 覆盖敏感文件（如 /etc/passwd） │
│ [ ] 使用固定文件名（可能被替换） │
│ [ ] 使用 /tmp（可能被符号链接攻击） │
│ [ ] 使用不安全权限创建文件 │
│ → 风险等级：中高 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟪 6. 输入验证检查 │
├──────────────────────────────────────────────────────────────┤
│ [ ] 接受用户输入 │
│ [ ] 对输入进行严格校验 │
│ [ ] 对输入进行过滤 │
│ [ ] 对输入进行长度限制 │
│ [ ] 使用不安全函数（如 gets、strcpy） │
│ → 风险等级：中 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ ⬛ 7. 逻辑漏洞检查 │
├──────────────────────────────────────────────────────────────┤
│ [ ] 允许用户绕过权限检查 │
│ [ ] 允许用户执行未预期功能 │
│ [ ] 存在 race condition（TOCTOU） │
│ [ ] 存在 symlink 攻击点 │
│ [ ] 存在不安全默认行为 │
│ → 风险等级：中 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟫 8. 程序依赖检查 │
├──────────────────────────────────────────────────────────────┤
│ [ ] 外部库 │
│ [ ] 配置文件 │
│ [ ] 插件 │
│ [ ] 脚本 │
│ [ ] 其他可控资源 │
│ → 风险等级：中 │
└──────────────────────────────────────────────────────────────┘

┌──────────────────────────────────────────────────────────────┐
│ 🟩 9. 运行时行为分析 │
├──────────────────────────────────────────────────────────────┤
│ [ ] 使用 strings 查看可疑字符串 │
│ [ ] 使用 ltrace 查看库调用 │
│ [ ] 使用 strace 查看系统调用 │
│ [ ] 检查是否调用外部程序 │
│ [ ] 检查是否访问敏感文件 │
└──────────────────────────────────────────────────────────────┘
